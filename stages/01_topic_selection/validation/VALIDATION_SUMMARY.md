# 定题前短验证结果

2026-11-26 · MCM/ICM 校赛模拟赛

**仍建议优先选 B 题，定题前确认首炉的可吊与座包窗口，以及关键站点的轨道可达性。** B 题在名义条件下已有经回放检查的可行轨迹，而且空包限制由 450 吨行车运送后仍可排通。它对座包提前量和行程时间有明显敏感性。A 题的两类留出测距与前墙剖面通过了本轮筛查，后墙尚不能稳定辨认。因此，目前的实测结果不足以将 A 题提到首位。

## B 题 · 确定性共轨调度

从 3 号连铸机的一个浇次取四段运输。两段重包从 LF1 到 CC3，另有前一炉的空包经 2# 倒渣位转至渡车。原始记录显示空包回程与其中一段重包运输重叠。两条计划、三条工序记录和三条连铸记录已逐项对回原表。复跑所需的逐条输入留在取得授权附件的本机。 [外部输入哈希](source_manifest.json)

用小规模枚举检查四段运输的先后与分配。每次只安排一个有载任务，允许其他行车空载移到让行点。五辆行车的位置以分段线性轨迹记录。回放检查总吊重、站点、出发与到位、翻渣前序、轨道边界与相邻车间距。速度、净距和坐标使用归一化单位。两组倒渣与渡车相对位置是测试假设，途中及待命的行车均参加净距核对。同浇次顺序使用计划窗口，重包最早可吊用历史实际起吊时刻作为保守代理。空包交接上界用历史放下渡车时刻，翻渣用历史作业时长。窗内未计未选中炉次的并发占用、车道横向运动、设备与待避区的实际容量。

| 验证项 | 实测结果 |
| --- | --- |
| 名义排程 | 2 分钟座包提前量、中等行程时间、东侧回程假设、净距 3 轨道单位。四任务全部完成，间距下界连续满足 |
| 限制空包仅用 450 吨行车 | 名义排程仍通过。重包均在 450 吨载荷范围内，求解方案由 3#450 承运两段重包，5#450 承运两段空包 |
| 首炉名义余量 | 模拟座包比规定的到位期限早 56.5 秒 |
| 敏感性 | 每种车型规则各测 36 个参数组合，均为 27 个有可核验轨迹、8 个触发首炉行程下界、1 个在当前串行构造内无候选。组合计数描述筛查范围 |

最能改变定题的是首炉。历史起吊与计划开浇间隔 391 秒。若必须提前 3 分钟座包，即使忽略让行和空驶，首炉也只剩 211 秒。用同站对两次历史吊起至座包耗时 182、247 秒作快慢代理，其中点 214.5 秒已超 3.5 秒，慢速代理超 36 秒。若实际可吊时刻早于历史起吊，或允许更短的座包提前量，结论会改变。这里的下界仅对该组代理参数成立。另有一个西侧回程、较大净距、慢速组合未找到串行排法，该结果只涉及所试构造。

## A 题 · 留出测距和单行剖面

只取第 4 行的 7 个接收通道。每组保留首个数据包，折叠四个周期后做匹配滤波。用空场估计相对直达校准和模板，利用双基地距离关系进行包络测距。每类 20 组按编号奇偶固定划分，奇数组估一个偏移量，偶数组只作误差评估。墙体 33 站按采集顺序做包络反投影，使用图示横移轴约定和空气走时，分别检查全孔径、奇数站、偶数站。另复跑一次限幅线性幅度增益，对同一组数据、同一几何和判据做对照。 [冻结的筛查配置](a_radar_echo/problem/pilot.json)

| 验证项 | 实测结果 |
| --- | --- |
| 墙体留出测距 | 10 组。绝对误差中位数 3.10 cm，MAE 4.56 cm，最大绝对误差 16.80 cm |
| 金属板留出测距 | 10 组。绝对误差中位数 1.30 cm，MAE 1.66 cm，最大绝对误差 4.50 cm |
| 前墙 2D | 无增益版本在全孔径与两个分孔径中均得到正斜率的近场条带，位置与图示约定一致。图示为轮廓参考 |
| 后墙 2D | 有增益和无增益的远区主峰均落在搜索下边界 1.30 m，未在图示后墙约 2.0 m 处形成通过判据的稳定主脊线。增益将全孔径远区峰值相对远区中位数的对比由 4.82 dB 改为 2.20 dB |

两个距离中位误差均小于预定的 10.7 cm 门槛。后墙筛查结论只适用于这一行、这套包络处理、坐标假设与两种增益设置。此次没有检验跨站相干标定、分层走时或三维目标定位。 [测距逐组结果](a_radar_echo/results/ranging_groups.csv) · [无增益剖面](a_radar_echo/figures/wall_aperture_split.png) · [限幅增益剖面](a_radar_echo/figures/wall_aperture_split_gain.png)

## 定题建议

先请团队确认 B 题两条信息：首炉从 LF1 何时真正具备起吊条件，CC3 最晚何时必须座包，以及 CC3、2#倒渣位和 1#–3# 渡车在 EF 跨的实际站点与可达行车。前者决定连铸硬窗口，后者决定能否复用这条无跨越构造。B 的名义排程和两个备选车型设定均提供了可检查的起点。若现场参数拿不到，可共同决定是否接受只对归一化布局和明确区间成立的模型结论。

若上述条件使 B 的关键任务确实跑不通，现有 A 结果只能支持测距与前墙处理。改选 A 前，把有限时间集中在后墙回波识别与几何校准，获得更强的独立证据后再投票。两题均未在此阶段做全量求解。

## 复跑

在项目根目录激活项目 Conda 环境后，从 PowerShell 执行。每个题目的 Workbench 工作区独立，分别产生 runs/ 下的运行清单。

~~~powershell
$python = (Get-Command python).Source
$mtd = '.agents/skills/mathodology-workbench/scripts/mtd.py'
$pilot = 'stages/01_topic_selection/validation'
& $python -B $mtd run --root "$pilot/b_crane_dispatch" --name b_crane_pilot -- $python -B code/run_pilot.py
& $python -B $mtd run --root "$pilot/b_crane_dispatch" --name b_crane_heavy_only -- $python -B code/run_pilot.py --heavy-only-empty
& $python -B $mtd run --root "$pilot/a_radar_echo" --name a_radar_pilot -- $python -B code/run_pilot.py
& $python -B $mtd run --root "$pilot/a_radar_echo" --name a_radar_gain_pilot -- $python -B code/run_pilot.py --gain
~~~
