**现场参数优先核对三件事。** B 核实短窗的可吊上下界和接车条件，A 明确座包、计划截止与供钢硬边界，C 核对五车物理排序、站点路径许可、载荷安全间距和故障续行条件。正式可调度任务与条件分析使用同一接口。阻塞任务保留在覆盖与统计台账。

## 下一阶段执行顺序

1. **B 先接事件与任务。** 从原始计划和预处理产物建立需求台账、准入分档和站点配置。先给共享回归实例与 B 短窗授权配置，标清每个替用的代理与待核参数。
2. **C 先交检查器。** 按实现契约实现独立事件和轨迹回放。跑 C 三个反例及正例，覆盖停轨阻挡、内部净距极值、带载制动与恢复，补接驳、载重、容量和同刻交接。
3. **A 实现 Q1。** 先固定 FCFS、余量规则和同一个候选生成器，能独立回放后再加预调位、并行预约、两个有真实竞争的窗口和必要的短窗 MILP。
4. **在通过 Q1 后扩展 Q2/Q3。** B 接入同义历时、按时间留出和配对样本，A 策略只用可见信息，C 验证冻结前缀、制动占轨与持有继承。最后对照承诺、工艺和恢复分类。

本轮已复跑既有短窗程序与 C 反例算术。完整调度器、实时发布和全量现场验收属于下一阶段。对尚未核实的拓扑或工艺截止，只发布条件结论。
