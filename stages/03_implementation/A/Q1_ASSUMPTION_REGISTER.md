# Q1 确定性规划参数登记

基线为远端 `main` 的 `88e77fb`，包含 B 在 PR #6 的最终交付。下列配置在首次运行前登记。真正的现场可吊、几何和许可仍列为待证。本轮使用 [冻结统一模型](../../02_modeling/model_spec.md)、[范围修订](../../02_modeling/model_scope_revision.md) 和 [B 数据交接](../B/Q1_DATA_HANDOFF.md)。

## 场景和时间

Q1W06 的炉次、路线、腿和包身份链接来自 B 冻结的历史回放任务结构。离线情景假定这些结构在规划开始时已知。计划时点来自明确标为计划的记录，历时优先使用同义的计划差值或预先登记的历史分位。B 的两小时历史窗口仅用于原来的在线边界检查。离线时域从入选炉次最早计划转炉结束开始，延伸到最晚已选计划终浇后 3,600 s，首尾都由计划决定。模型中的零时刻和 B 原窗口零时刻分别保留。炉次内没有更早的在途吊运；五车初始停驻，其他既有占用未知。该状态是假设。

两对相邻计划供钢区间重叠。当前案例以计划开浇作为目标与最早启动参考，由座包准备和前炉完成约束推导单容量供钢时刻。计划最迟座包为 $C_i-120$ s。严格目标实验拒绝越过该界，独立的诊断实验允许安全迟到并另计计划偏差。实际允许的最大断供间隔、现场硬准备时间和前后窗供钢状态缺证。条件供钢时刻只用于保序、容量和等待核算。

## 复用钢包及外部边界

身份映射只继承 B 核准结果或已唯一链接的身份。保留跨炉键，不用炉次号重建实体，不复制原始表格和编号到共享结果。已确认同一包跨炉复用时，将后炉的转炉取点接到前炉在规划台账中的末端交接。缺少返回就绪或接驳轨迹时继承阻塞。保留三条待确认的 EF 运段及其外部服务，不改变范围或默认为无限容量。若未来核实落渡车接点和返程授权，应在独立情景内补足前序、占用、持有转移和释放后再比较。
