## 随机输入与策略比较

按 B 的设备、路线和工序逐级匹配冻结模型。两窗的 CC3/L0 采用已验证选定的对数正态比例，乘该炉的计划均值后得到正供钢历时。合格 LF1 邻对固定为同设备、同浇次的计划次序双位置，未配对者使用该层训练经验分布。经验捐赠只来自授权训练池。所有组位置在派车前冻结。转炉以计划出钢完成锚点和准备时间产生条件就绪，本实验未另抽转炉出钢完成偏差。翻渣抽取服务历时，交接释放仍走前序与持有约束。

对每个重复，输入种子由 B 规定的紧凑 UTF-8 JSON 和 SHA-256 生成。独立工步用事件键，配对块以固定的首事件键选取一个块。同一重复的三种策略使用同一历时表和物理参数。比较按窗、配置和 replicate ID 配对，三条策略的完成、准点等公共分母固定。区间为条件重复的配对均值 t 区间，反映当前随机模型和有限复制下的 Monte Carlo 误差。窗口及情景均为条件对照。

## 动力学与连续约束

位置与净距使用米，时间使用秒。单条授权 EF 轨道按限速边界分段。由前、后向可达速度共同确定跨区边界速度，保证入区前已制动。分段恒加速度连接位置与速度，反向前先停车。五台行车按固定相对次序占轨，两台 150 t 行车保持停驻约束。相邻间距在共同断点的每个区间内为二次函数，检查两端与内部驻点即可覆盖该区间的最小值。

主条件为基准尺度、分散初态、名义运动与基准净距，分位策略取 P90。尺度情景按 B 的定义同时换算空间几何及其尺度附属净距，另做固定基准尺度的独立净距敏感性。速度与加减速度档使用 B 的统一水平，仍受声明的区段限速约束。

方案比较保持事件状态、候选生成和安全筛选共用。先为每个任务选择最早可行交付的车辆，再以 FCFS、最紧余量或余量减缓冲排序任务。若直接比较同一任务不同车辆的余量，慢车会因余量较小而得到更高优先级。首次运行的决策日志复现了该问题，新增测试覆盖后，以原任务、种子和重复数重新运行。仅使用校正后的见证。

候选搜索从已可见就绪任务出发，保守地预留目的接收位，在开浇前保留可用空包位。给定已占轨车辆，尝试直达及通过登记停车点的有限让行模板。当前实现没有用于未就绪任务的预调位、任意载重途中停车、撤销预约或全局搜索。未完工可能源自工艺阻塞、候选搜索或终止时域。分位缓冲只沿目标前的剩余已声明工序累加边际量，不解释为联合分位数。诊断性迟到情景和额外严格目标情景分别报告。冻结边界未授予现场恢复许可。
