# Stage 03-Q2-A · 条件实验报告

**三种任务优先规则在本次实验中均产生相同的派车决策和结果。** 在冻结名册、共同候选生成器及已批准的条件动力学下，26,207 个派车时点每次都只有一个有效候选任务。因而本试验没有观测到分位缓冲在任务选择上的增益。保留 FCFS 作为对照足以复现这些窗口的当前结果，三种规则仍可用于有实际可选竞争的后续验证。

## 设计和验证对象

用相同任务、计划、初态、事件可见性、物理权限和预先固定的随机历时配对 FCFS、Tight Margin 和 Quantile Buffer。每个窗口基准 500 次，额外严格座包目标 500 次，单因素敏感性各 200 次。共 24 个窗口/配置组、6,000 个配对重复、18,000 次策略仿真。固定主种子为 20261128。先导每窗每模式 3 次，用于检查事件和输出。

主条件使用 B 的基准尺度 4 m/归一单位、分散初态、名义运动与 16 m 参考点间距门槛。分位策略为 P90。Q1W01 和 Q1W07 是彼此无重叠的两个条件窗口，其生产环境与窗口筛选方式限定了可推广范围。名册可用于批规划，策略的实际就绪来自仿真中的已完成工序和准备事件。 [建模决策](Q2_MODEL_DECISIONS.md)

当前条件中每窗有 4 条确认 EF 任务缺声明服务路径。余下的未完成由可见前序、接收位保留占用、回程无有据释放、起吊等待界及有限候选导致。为区分策略选择和实现偏差，首次实验的车辆排序错误已修复并新增回归测试。正式结果使用任务间排序与任务内共同车辆选择，首次试验结果没有纳入对比。

## 单因素结果

同窗使用相同的前 200 个重复，三条规则依旧产生相同结果。下表为每组完成均数和准点均数。

| --- | ---: | ---: |
| 名义值前 200 次 | 4.310 / 1.700 | 4.330 / 1.665 |
| 尺度 3 m/归一单位 | 4.485 / 1.795 | 4.555 / 1.825 |
| 尺度 5 m/归一单位 | 4.190 / 1.595 | 4.220 / 1.585 |
| 拥挤初态 | 4.705 / 1.995 | 4.560 / 1.890 |

拥挤初态改变了车队相对于取放点的位置，本模型的完成表现提高。该变化同时受候选时机和既有轨道预约影响。净距改动对两个窗口作用不同。LF1 独立经验对照改变了边际捐赠与相关结构，完成数下降，不能由此单独识别相关性的因果影响。

## 验证与证据分级

- **数学性质。** 连铸比例按 B 冻结的训练期均值归一，解析运动段的端点和内部极值构成 Q2 恒加速度模板的连续净距判据。
- **条件计算。** 每条策略轨迹通过五车连续性、限速、加减速、相邻净距、占用和持有重放。比较保留统一窗口和未完成截尾。两次完整生成的 76 个本机文件逐字节一致。
- **工程回归。** Q2 共 20 项测试通过，包括 C 的 4.2 内部极值反例、未来历时变更下当时决策不变及共用同任务车辆排序。Q1-A 19 项、Q1-B 47 项、原 44 组 Q1 排程的 67 份 JSON 字节级校验、Smoke 和 Workbench 检查均通过。
- **尚待现场核验。** 真实可派资格、轨道尺度、车辆包络、合法待避、渡车接收与释放、回炉及连续供钢条件。候选器为有限规则，未完成率与策略优势不能外推至已核现场。C 的独立验收待本 PR 合并。
